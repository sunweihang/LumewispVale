# 特效预览

编辑器扩展：无需 Play，即可 scrub 角色动画、预览挂点特效，并按角色保存/读取绑定配置。

## 启用

1. **扩展 → 扩展管理器 → 项目** → 启用 `effect-preview`（资源管理见 `effect-editor`）
2. **扩展 → 特效管理器 → 特效预览**

改完插件后请 **禁用再启用** 一次（或点重新载入）。

## 用法

1. 打开面板，选角色 → **一键打开预览场景并放入角色**
2. 选动作 → 拖时间线；可添加特效点、调挂点偏移
3. **保存当前角色** / **读取当前角色** → 读写 `assets/resources/json/effect_preview.json`

特效 Prefab 目录：`assets/resources/effects/{id}/`（`sfxUrls` / `res.json` 指向该路径；CreatNode 名仍为 `SFX_*` / `VFX_*`）。

## 菜单（挂在「特效管理器」下）

| 项 | 作用 |
|----|------|
| 特效预览 | 打开特效预览面板 |
| 重载预览场景脚本 | 场景脚本丢失时用 |
