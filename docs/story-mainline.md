# 微光溪谷 · 主线剧情与地图开放

> 设计文档。落地以 Luban `TQuest` 链 + `QuestSystem` 为准；本文是节奏与叙事权威。

## 一句话

继承溪谷边缘农庄的你，在**紫晶陨石**坠落异象后，一步步稳住农场、融入小镇、修复社区中心、探明晶脉，并在丰收节让微光归于土地。

## 叙事主轴

```
农场教程 → 查看陨石 → 解锁小镇 → 镇长报到
  → 商店/公告板 → 社区中心立项
  → 矿洞异变 → 海滩潮声 → 密林旧页
  → 晶脉共鸣 → 丰收节收束
```

## 技术约定

- **条件新增** `ConditionType.Flag`：`param` 为旗标名，`num` 为需要次数（通常 1）。
- **旗标**由 `QuestSystem.noteFlag` 写入，并经 `GameState` 跨场景保留。
- **地图锁**：`GameState.unlocked.town`；未解锁时路牌只提示，不切场景。
- **切场景**：`MapTravel`（`Main` ↔ `Town` ↔ `Mine`），切前把背包/金币/任务进度写入 `GameState`。
- **配置**：无 Excel 时直接改 `assets/resources/config/tquest.json` 等；若恢复 Luban Datas，改完需 `npm run gen:config`。
