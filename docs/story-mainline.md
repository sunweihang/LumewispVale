# 微光溪谷 · 主线剧情与地图开放

> 设计文档。落地以 Luban `TQuest` 链 + `QuestSystem` 为准；本文是节奏与叙事权威。

## 一句话

异世界英雄身负重伤、记忆尽失，被溪谷少女·露穗救下后暂居农庄——她手把手引导你先稳住农场，再融入小镇、学会买卖、修复社区中心、探明晶脉，并在丰收节让微光归于土地。

## 主循环（日循环远征）

每天从农庄出发，用有限的**时间**和**体力**推进溪谷探索；晚上回小屋睡觉，作物过夜生长，第二天带着补给再上路。

- **长期赢面**：沿主线地图找回微光（海滩 → 密林 → 深矿 → 丰收节）。
- **农庄是营地**，不是通关条件：睡觉、种粮换钱、打造/购买远征工具、补体力。
- 社区收集包、友谊、扩田升级不是本阶段脊梁（春厅点亮只是第二章剧情节点）。

| 层 | 节奏 | 玩家决策 |
|----|------|----------|
| 日 | 06:00→约 02:00，体力 100 | 种/卖/买干粮，还是进镇、进矿赶主线 |
| 章 | 主线地图门控 | 这一章要带什么物资出门 |
| 年 | 春夏秋冬 + 丰收节 | 季节卡作物与节庆 |

**日规则**

- 时钟权威在 `GameState`（切场景不重置）。点农场小屋门确认后睡觉：日历 +1、体力回满、06:00、作物结算。
- 02:00 未上床则晕倒回小屋，次日体力 70%。
- 体力：拔草/收获 1、浇水 2、锄地/挖矿 4、砍树 5、钓鱼 8。走路不耗体。干粮 +40。
- 浇过水的作物在睡觉时成熟（肥料/催熟剂 = 立刻当睡过一晚）。地块随 `GameState` 跨场景保留。
- 店铺营业：种子/杂货/渔具 09:00–18:00；矿石店 08:00–17:00；酒馆 11:00–24:00。打烊只提示。公告板与矿洞全天。

## 技术约定

- **条件新增** `ConditionType.Flag`：`param` 为旗标名，`num` 为需要次数（通常 1）。
- **旗标**由 `QuestSystem.noteFlag` 写入，并经 `GameState` 跨场景保留。
- **地图锁**：`GameState.unlocked.town`；未解锁时路牌只提示，不切场景。
- **切场景**：`MapTravel`（`Main` ↔ `Town` ↔ `MayorHouse` ↔ `Mine`），切前把背包/金币/任务进度/地块写入 `GameState`。时钟与体力也在 `GameState`，切场景不重置。
- **配置**：权威源为 Luban Excel `SourceData/Datas/`（`quest.xlsx` / `craft_recipe.xlsx` 等）。改完跑 `npm run gen:config`。运行时只读 `assets/resources/config/t*.json`，勿手改 JSON。
